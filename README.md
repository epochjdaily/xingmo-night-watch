# 星貘夜航局 · Xingmo Night Watch

> 旧星图，新型掉线方式。

「星貘夜航局」是一个原创中文人格测评网站。它把十二星座的元素底色、中国传统二十八宿的文化意象，和当代年轻人的信息过载、AI 焦虑、已读未回、搭子社交结合在一起。

用户会经历 12 个数字生活场景，最终签收一份“夜班星官档案”。

## 创意设定

星貘是一只在宇宙档案馆值夜的小貘。它专门吞掉多余的通知噪音，再把人类没来得及回复的情绪分装进流星瓶。

网站于 2026 年 8 月创作，视觉与文案呼应英仙座流星雨与七夕节点。英仙座流星雨通常在 8 月中旬达到高峰，2026 年的活跃时段与传统七夕非常接近，因而成为「夜航局」的发射窗口。

| 星官人格 | 星宿意象 | 夜航能力 |
| --- | --- | --- |
| 开路星貘 | 角木蛟 | 在信息不全时开出第一条路 |
| 容光星貘 | 房日兔 | 读懂气氛，让人可以停靠 |
| 排阵星貘 | 斗木獬 | 把混乱拆成节点与备用路线 |
| 留白星貘 | 虚日鼠 | 不被即时反应绑架 |
| 造境星貘 | 奎木狼 | 把无形情绪做成可分享的世界 |
| 清醒星貘 | 昴日鸡 | 在算法和 AI 幻觉中保持校验 |
| 回信星貘 | 柳土獐 | 不一定秒回，但会真正回来 |
| 燃点星貘 | 星日马 | 用活人感打破冷启动尴尬 |

## 主要体验

- 可选生日月日，用十二星座元素对结果进行轻量校准
- 12 道原创情境题，覆盖群消息、AI 协作、算法沉浸、搭子社交等当代场景
- 8 种星宿人格，每种包含天赋、盲区、搭子关系和今夜微任务
- 信号强度、轨道边界、回复速度、流星行动四维剖面
- 可下载 1080 × 1440 PNG 夜航通行证
- 支持键盘、触屏、移动端和减少动效偏好
- 纯前端，不保存或上传生日与答题数据

## 本地运行

项目不需要安装依赖。在项目目录启动任意静态文件服务，例如：

```bash
python -m http.server 4173
```

然后打开 `http://localhost:4173`。

## 部署

仓库包含 GitHub Pages 工作流。向 `main` 分支推送后，在仓库的 **Settings → Pages → Source** 中选择 **GitHub Actions** 即可发布。

## 设计与图片

- 整体视觉采用“宇宙档案室 × 编辑式霓虹印刷”方向
- 星貘 IP 和社交封面使用 OpenAI 图像生成工具制作
- 其余星轨、星宿符号和界面元素由 CSS 与 Canvas 绘制
